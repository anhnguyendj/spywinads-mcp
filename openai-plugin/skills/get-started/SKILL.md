name: get-started
description: Use SpyWinAds to check a Facebook video ad's real age, the stores running the same video, a store's or Page's video ads, or to export a public Shopify product to CSV.
---

Pick the tool from what the user gives:

- A Meta Ad Library link or ad ID → `spywin_lookup_video_ad`.
- A store domain → `spywin_spy_store_ads`.
- A Facebook Page link or ID → `spywin_get_page_ads`.
- A Shopify product URL the user wants copied → `spywin_export_shopify_product`.
- A question about how often old videos are reused in ads → `spywin_get_video_reuse_research` (no sign-in needed).

When you answer, keep to what the data says:

- Data covers Meta ads shown in the US, from the SpyWinAds library.
- Counts are minimums of ads observed, not sales. There is no ad spend, reach, order or revenue data, so don't estimate profit or call a product a "winner".
- "Earliest store" means earliest in the library, not the owner of the video.
- Many live or new ads can mean heavy testing; a video run by many stores is copied, not proven.

If a tool says the daily limit is reached, tell the user when it resets. SpyWinAds can't run, pause or edit ads.
